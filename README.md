# Plataforma-control-de-habitos
Plataforma que permite llevar un control y registro de habitos en el dia a dia

## Funcionalidades
- Agregar y eliminar hábitos
- Marcar cada hábito como cumplido en los últimos 7 días
- Racha de días seguidos por hábito 🔥
- Barra de progreso del día
- Modo oscuro automático (según la configuración del sistema)
- Los datos se guardan en el navegador (`localStorage`)

## Cómo usarla
No necesita instalación. Abre `index.html` en tu navegador (doble clic).

## Estructura
```
index.html      → estructura de la página
css/styles.css  → diseño y colores
js/app.js       → lógica: guardar hábitos, marcar días, calcular rachas
```
